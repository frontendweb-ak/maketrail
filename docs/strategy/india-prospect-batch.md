# India validation prospect batch — research leads

**Status:** Preliminary public-source shortlist; not contacted  
**Prepared:** 2026-11-25  
**Market focus:** India, first batch  
**Purpose:** Give the first outreach cycle a small, inspectable starting pool. This is not a qualified lead list, endorsement, partnership list, or evidence of buyer demand.

## Important interpretation

A public company profile only indicates that an organization may be relevant to interview. It does not establish that it is a development agency with repeated module-reuse needs, that the right decision-maker has been identified, or that the organization wants to participate.

Likewise, a maker directory or open-source project index is a discovery channel—not proof that a listed creator owns distributable rights, wants to sell, can support buyers, or has a product suitable for Maketrail.

**No one below has been contacted. No interview, consent, creator commitment, product qualification, sale, or integration is claimed.** Assign participant IDs only when an actual prospect is selected for outreach. Store names/contact details and raw evidence in a private system, not this public file.

## 3. Creator screening priority

For the first creator batch, prioritize products that:
- Solve a clear, repeatable software capability rather than a one-off client project.
- Have a public demo, documentation, release history, or usable example.
- State a supported stack/version and known limitations.
- Have a clear license and credible ownership/distribution-rights path.
- Have a maintainer who can explain updates and support.
- Could be integrated by a buyer or qualified implementation provider.

Initial categories remain hypotheses from the parent validation plan. Do not select a category merely because a directory has many listings. Let buyer interviews determine which capabilities are repeatedly painful and costly.

## 4. First outreach batch recommendation

Keep the first batch deliberately small:
- **Buyers:** qualify the three organization leads above; select up to three relevant decision-makers only after public-profile review.
- **Creators:** manually review 8–10 products from the discovery channels; shortlist up to five creators only when there is a concrete product and a credible public contact route.
- **Interviews:** aim for a balanced first set of conversations, but record the actual mix and do not substitute directory counts for completed interviews.

For each selected person:
1. Create a participant ID in the private research/contact system.
2. Record only non-identifying metadata in the public participant tracker.
3. Confirm the person's role and relevance before sending an invitation.
4. Use the relevant template in [outreach playbook](outreach-playbook.md).
5. Record actual contact, response, consent, and interview state in [validation operating kit](validation-operations.md).

## 5. Research limitations and next update

- This is a small convenience sample, concentrated in Uttar Pradesh/NCR and online Indian maker directories.
- It does not represent the Indian agency or creator market.
- Company service descriptions are self-published; no customer references, delivery quality, legal status, or financial claims have been independently audited.
- Creator directory listings are discovery signals only. No individual creator or product is qualified in this document.
- The current sources do not establish demand, willingness to pay, product-market fit, or transaction feasibility.

Update this file only when a lead has been manually reviewed or new evidence materially changes its priority. Record actual outreach and interviews in the operating tracker; do not change a prospect's status based on assumptions.
