# Feature specifications

The [feature map](feature-map.md) is the master inventory of proposed capabilities, priorities, dependencies, and candidate MVP boundaries.

Detailed feature specifications belong in this directory. Create them only after the relevant problem has been validated and the feature has been selected. Each specification must follow the template in the feature map and include acceptance criteria, permissions, failure states, security/privacy considerations, and test scenarios.

A P0 label in the feature map is a planning hypothesis, not implementation approval.
