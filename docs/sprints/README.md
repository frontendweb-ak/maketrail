# Sprint planning

## Current phase: validation

The first delivery cycle is a market-validation cycle, not an application engineering sprint.

### Validation cycle — 30 days

**Goal:** collect enough buyer, creator, product, and transaction evidence to select a narrow initial marketplace problem.

Workstreams, schedule, interview prompts, metrics, and decision criteria are in [the market validation plan](../strategy/market-validation.md).

### Weekly review format

At each weekly review, record:
- Goal and planned outcomes.
- Completed work and links/evidence.
- Buyer interviews and qualified requirements.
- Creator interviews and qualified products.
- Transactions and integration outcomes.
- Risks, blockers, and changed assumptions.
- Next week's priorities.

Do not mark an activity complete without evidence.

## Engineering sprints

Engineering sprint plans will be created after the validation decision and approval of the first MVP scope. Each engineering sprint must have a goal, prioritized issues, dependencies, acceptance criteria, test expectations, and a demo/review outcome.
